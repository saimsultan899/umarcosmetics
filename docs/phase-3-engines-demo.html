Phase 3 engines — live demo

The three Pakistani-distribution calculation engines built this phase, running in your browser exactly as the app's src/lib/pricing/{uom,discounts,tax}.ts modules do. Play with the inputs to validate the logic (e.g. paste your real scheme strings). checking…

1 · Carton ⇄ Piece (UOM)

Base unit is pieces; packing = pieces per carton. Enter cartons + loose, or total pieces.

2 · Scheme / discount parser

Turns free-text product.scheme into a structured rule + rupee discount / free goods.

3 · GST / FED (FBR) — single line + invoice roll-up

Standard GST 18%, further tax 3% for unregistered buyers, optional FED. Taxable value = line net.
